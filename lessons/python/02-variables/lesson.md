# Keeping track of things

A **variable** is a name that holds a value. You create one with `=`.

```python
gold = 50
gold = gold + 10   # now 60
```

You can also write `gold += 10` as a shortcut.

## Your quest

Your hero starts with `health = 100`. A goblin hits for 25 damage.

1. Subtract 25 from `health`.
2. Print `health`.

The program should print `75`, and `health` should be `75` at the end.
