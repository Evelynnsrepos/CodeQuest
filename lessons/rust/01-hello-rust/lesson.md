# Your first program

Every Rust program starts in a function called `main`. `println!` prints a line of text. The `!` means it's a **macro**, a special kind of function.

```rust
fn main() {
    println!("Ready for adventure");
}
```

Each statement ends with a semicolon `;`.

## Your quest

Make the program print exactly:

```
Hello, Rust!
```

Rust is compiled before it runs, so the first Run takes a few seconds.
