# Your first program

TypeScript is JavaScript with **types** added. You write `.ts` files, the TypeScript compiler checks them for mistakes, and then they run as normal JavaScript. Web apps, VS Code, Deno and Bun all use it, and so do game engines like Phaser and Babylon.js.

`console.log()` prints a line:

```ts
console.log("Press start");
```

Lines usually end with a semicolon, and comments start with `//`.

## Your quest

Make the program print exactly:

```
Hello, TypeScript!
```
