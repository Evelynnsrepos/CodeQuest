# Your first script

Lua is a small, fast scripting language. Games use it a lot: Roblox (as Luau), LÖVE, Defold and PICO-8 all run Lua code.

`print()` shows text on the screen:

```lua
print("Press start")
```

Lua doesn't need semicolons, and comments start with `--`.

## Your quest

Make the program print exactly:

```
Hello, Lua!
```
